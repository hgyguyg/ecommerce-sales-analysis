# 电商销售数据分析 — 数据模型设计

## 数据分层架构

┌─────────────────────────────────────────────┐
│                  ADS 层                      │
│  业务分析查询: Pareto / Cohort / RFM ...     │
│  → 10+ 条复杂 SQL                            │
├─────────────────────────────────────────────┤
│                  DWS 层                      │
│  汇总聚合: 日度销售 / 品类月度 / 客户行为      │
│  → 4 张汇总表                                │
├─────────────────────────────────────────────┤
│                  DWD 层                      │
│  清洗后明细: 订单事实宽表 + 3 张维度表        │
│  → 1 张事实表 + 3 张维度表                   │
├─────────────────────────────────────────────┤
│                  ODS 层                      │
│  原始数据: orders_raw / customers_raw / ...  │
│  → 3 张原始表                                │
└─────────────────────────────────────────────┘

## 数据关系

dim_customer ──┐
dim_product  ──┼── dwd_order_fact ──┬── dws_daily_sales
dim_promotion ─┘                    ├── dws_category_monthly
dim_date      ──────────────────────├── dws_customer_behavior
                                    └── dws_promotion_effect

## 数据规模
- 订单数: ~120,000
- 客户数: ~15,000
- 商品数: ~2,000
- 时间范围: 2022-01 ~ 2023-12 (24个月)

## 核心指标
- GMV / 实收 / 客单价 / 折扣率
- 复购率 / 留存率 / 流失率
- 促销 ROI / 退货率
- 区域 GMV 集中度
